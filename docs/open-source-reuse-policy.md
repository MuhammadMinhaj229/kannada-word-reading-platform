# Open-source reuse policy

- Treat LEVANTE as a methodological and behavioural reference. Do not copy its application code, item content, graphics or recordings without an explicit licence review.
- The LEVANTE core-task repository identifies core task/item-bank material under CC BY-NC 4.0. This may not fit a commercial or mixed-licensing release.
- ROAR-LDT has a separate Stanford academic software licence. Do not copy its source without reviewing the complete licence and obtaining permission where required.
- Prefer original code for the Kannada assessment UI, trial logic, session handling, reward system and visual assets.
- Keep notices for all third-party dependencies and any approved media/font assets.
- This repository remains private until PHFI/CDLR confirms intellectual-property ownership and distribution terms.
