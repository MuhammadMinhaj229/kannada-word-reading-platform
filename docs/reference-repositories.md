# Research and implementation references

## Behavioural task reference

- LEVANTE core tasks: https://github.com/levante-framework/core-tasks
- LEVANTE Word Reading measure: https://researcher.levante-network.org/measures/direct-child-measures/language/word-reading
- ROAR LDT public reference: https://github.com/yeatmanlab/ROAR-LDT-Public

## Selected technical libraries

- jsPsych: https://github.com/jspsych/jsPsych — browser-based behavioural experiments, timeline and response data.
- Serwist: https://github.com/serwist/serwist — service worker and offline precaching for Next.js.
- Dexie: https://github.com/dexie/Dexie.js — IndexedDB wrapper for browser-local data persistence.
- ExcelJS: https://github.com/exceljs/exceljs — XLSX workbook parsing and authoring.

## Reuse policy

Study task structure can be inspected as a methodological reference, but do not copy third-party code, stimuli, assets or recordings into this app without verifying the applicable licence and obtaining permission where required. Maintain dependency notices and review licences before release. No third-party research stimuli are included in this repo.
