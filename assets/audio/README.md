# Kannada instruction audio assets

The field application uses bundled, offline Kannada recordings only. Device TTS and remote speech services are not substitutes for the approved recordings.

`audio_manifest.json` is the single manifest for clip paths, approval references and versioning. The supplied 12-minute source recording is not included as a playable clip because it has not yet been reviewed, segmented into the required instruction moments, or tied to a written PHFI/CDLR audio approval.

Before enabling playback for field sessions, add the approved recordings under this directory, update the manifest with each asset path, recording version, approver and approval reference, and verify every clip on the target tablet with network access disabled. Keep scored stimuli silent unless the PI approves a protocol change.
